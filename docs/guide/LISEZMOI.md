# Source du guide étudiant

`guide.html` est la source de `docs/Guide_etudiant_trame_beton.pdf` (A4, police Bricolage Grotesque).
Pour régénérer le PDF : ouvrir `guide.html` dans Chrome, puis Imprimer › Enregistrer au format PDF
(marges : par défaut, graphismes d'arrière-plan : activés).

- Captures de l'aperçu : `img/interface.jpg`, `trace`, `motif`, `beton`, `vue`, `robot`, `exports`,
  `bilan`, `simulation`, `couches`, `gizmo` ; les annotations (cadres et pastilles) sont en HTML,
  positionnées en % dans `guide.html`.
- Captures GitHub (`gh_*`) et Grasshopper : annotations incluses dans l'image.
