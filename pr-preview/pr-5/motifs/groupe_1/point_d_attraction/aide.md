# Point d'attraction

Les trois séries de lignes se courbent doucement vers les points d'attraction.
Les lignes restent imprimées dans l'ordre A, B, C : les dernières passent au-dessus
des précédentes aux croisements.

## Réglages

- **Distance minimale** : écart entre deux lignes d'une même série. Gardez une
  valeur assez grande pour la largeur du cordon.
- **Nombre de points** : affiche un, deux ou trois points. Mettre `1` supprime
  les points 2 et 3 du calcul.
- **Position horizontale / verticale** : place chaque point sur la palette,
  en millimètres.
- **Force** et **distance d'influence** : règlent la courbure autour des points.

La page affiche ces réglages sous forme de curseurs. Pour placer un point
directement en cliquant sur le canevas, il faudra un ajout dans l'interface web ;
ce motif fournit déjà les positions réglables nécessaires au calcul.
