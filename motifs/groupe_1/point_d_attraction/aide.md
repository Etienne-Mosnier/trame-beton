# Point d'attraction

Les trois séries de lignes se courbent doucement vers les points d'attraction.
Les lignes restent imprimées dans l'ordre A, B, C : les dernières passent au-dessus
des précédentes aux croisements.

## Les points, directement sur la palette

- **Double-clic sur la palette** : ajoute un point d'attraction (8 au plus).
- **Clic sur un point** (boule orange) : les flèches apparaissent, fais-le glisser.
- **Double-clic sur un point**, ou touche Suppr : le supprime. Sans aucun point,
  les lignes restent droites.

## Réglages

- **Espacement** : écart entre deux lignes d'une même série. Gardez une
  valeur assez grande pour la largeur du cordon.
- **Force** : de combien les lignes se déplacent vers les points.
- **Rayon d'attraction** : jusqu'à quelle distance autour de chaque point
  les lignes sont attirées.
